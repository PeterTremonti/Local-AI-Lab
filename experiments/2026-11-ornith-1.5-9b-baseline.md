## 7. Practical Context Recommendation

Observed performance suggests:

| Context | GPU allocation | Observed behavior |
|---|---|---|
| 98K | 100% GPU | Fast repeated generation |
| 128K | 92% GPU | Good long-input retrieval |
| 256K | 55% GPU | Successful retrieval, very slow generation |

**Provisional recommendation:** Use 128K as the practical working
context and reserve 256K for tasks that genuinely require it.

The 256K setting is technically achievable, but CPU offloading
substantially reduces interactive generation speed.

## 8. Current Assessment

Ornith-1.5 9B is a strong candidate for the primary local coding agent.

It combines:
- Approximately 76 tokens/sec warm direct generation.
- Full GPU residency at 98K context.
- Successful retrieval from approximately 105K input tokens.
- Successful retrieval from approximately 228K input tokens.
- Strong results in the Claude Code agent benchmark.

Further testing on a larger real-world repository is required.
